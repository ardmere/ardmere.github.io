// 02 — protocol

What ardmere does.

A composable stack for anyone who believes the rules of Web3 should apply to everyone equally—from anon devs to billion-dollar DAOs.

01 // 🔍

Contract Auditor

Automated EVM bytecode analysis. Detects hidden minting, backdoors, fee manipulation, and proxy traps with a single command.

02 // 🕸️

Whale Tracker

Real-time graph analysis of wallet clusters. Surface undisclosed insider coordination and wash-trading patterns before they move markets.

03 // 🗳️

Governance Oracle

Score DAO votes for concentration risk. Identify sybil attacks on snapshot proposals and publish verifiable results on-chain.

04 // 📡

Immutable Reports

Every finding is published to IPFS and anchored on Ethereum. No takedowns, no edits. The record is permanent.

05 // ⚡

Live Alert Feed

Subscribe to on-chain event streams for any protocol. Get notified the moment something anomalous hits the mempool.

06 // 🔓

Open API

All data is freely accessible. Query audit scores, wallet graphs, and governance metrics via REST or GraphQL—no API key required.

// 03 — manifesto

Why we exist.

The original promise of blockchain was trustlessness. You shouldn't need to trust a founder, a team, or a multisig. You should be able to verify everything yourself. But as the space scaled, that promise was quietly buried under complexity, obfuscation, and wilful ignorance.

ardmere exists because code is law only when everyone can read it. Because decentralization is meaningless when five wallets control 80% of a governance token. Because "open-source" is a lie when the contracts are verified but the intent is hidden.

We are not a security firm. We take no retainers. We publish regardless of who asks us to stop. Our findings live on IPFS and Ethereum— permanently, immutably, owned by no one. We answer only to the chain.

Join us. Run a node. Submit a report. Fork the codebase. The tools are free. The data is public. Transparency is not a feature— it is the foundation. → Read the full manifesto
